## Project Structure  
Each folder may contain the following files:  
1. **`.ipynb` file** – Jupyter Notebook with the implemented code.  
2. **`code_summary.txt`** – A brief summary describing the code’s functionality.  
3. **Report** – A detailed document presenting key results, observations, and insights.  
4. **Data files** – Input datasets used for analysis and calculations.  

## Documentation  
Techniques used in these projects have been documented in **`Techniques.docx`**, providing an overview of the methodologies applied across different analyses.
